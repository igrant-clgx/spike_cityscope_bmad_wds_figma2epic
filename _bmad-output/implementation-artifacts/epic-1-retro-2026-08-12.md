## 2. What Went Well

1. **Pipeline fidelity held end-to-end (the spike's core result).** Exact DESIGN.md/EXPERIENCE.md values landed verbatim in code and tests — 120ms micro-motion, the `rgba(220,53,69,0.10)` input-error glow, ≥44px targets, the AD-12/NFR-8 PII rules. Requirement IDs (FR/AD/NFR/UX-DR) traced cleanly through epic → story → spec → code with no drift.
2. **Architecture discipline was enforced, not just documented.** The inward-dependency rule held (domain + adapters import zero UI, grep-verified) and the `no-adhoc-hex` convention test mechanically enforces token-only colour.
3. **High review rigor via parallel adversarial reviewers.** Every story ran Blind Hunter + Edge Case Hunter in parallel; they converged on the real defects — Story 1.4's *retry-before-reading-body* bug and Story 1.5's *array-blind PII scan* — which were patched before finalize, not shipped.
4. **Deferred work compounded as designed.** The api-client error-handling item deliberately deferred from Story 1.1 was resolved in Story 1.4 exactly where the plan predicted — the dependency chain worked.
5. **Ahead-of-training toolchain navigated cleanly.** Next 16 / React 19 / TS 7 / MUI 9 / vitest 4 were stood up and kept green, with the environment quirks captured for reuse.

## 3. Challenges & Growth Areas

_No blame — systems and process only._

1. **Node-only test environment friction.** Choosing no jsdom/RTL keeps tests fast but forces `renderToStaticMarkup` for React tests; timers, rerenders, and hydration are awkward to cover. The Story 1.5 async thenable-rejection test needed manual microtask flushing to assert correctly.
2. **Toolchain quirks cost cycles (now documented, still latent).** TS7 removed `baseUrl`; `eslint-config-next` crashes on TS7 (moved to the flat `@next` plugin); global npm registry 404s (project `.npmrc` pin); system python lacks tomllib/yaml (`uv run` for BMAD scripts). Each is a trap for future epics if forgotten.
3. **Accumulating hardening debt.** Six `deferred-work.md` items: no inward-dependency lint/arch test, `tsconfig` missing `noUncheckedIndexedAccess`/`exactOptionalPropertyTypes`, convention test only catches hex (not `rgb()`/`hsl()`/named), api-client one-shot-body retry gap, header-bg/disabled palette wiring. None blocking; growth needs watching.
4. **PII guard is bounded, by design.** The `AssertNoPII` guard + runtime scan use a 10-key allow-list — `emailAddress`/`phoneNumber`/`street` evade it. A conscious spike-scope decision and a documented limitation, not exhaustive PII inference.

---

## 4. Key Insights

1. Intent survived the Figma→BMAD→implementation pipeline without drift — the spike's central hypothesis held for a foundation epic.
2. Convention/architecture tests (hex enforcement, layer purity) are cheap and high-leverage — keep investing in mechanical enforcement over documented conventions.
3. The two-parallel-reviewer loop is genuinely catching real bugs; it should be the standard, not an option.
4. Deliberate deferral with a written `deferred-work.md` trail works — provided each new epic *pulls* the relevant items forward.
