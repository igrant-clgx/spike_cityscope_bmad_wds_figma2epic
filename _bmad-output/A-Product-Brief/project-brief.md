## Project Scope

A ReactJS front-end rebuild of the "Renovation Calculator Report" — a standalone web tool accessed via direct URL (no discovery layer or auth in v1).

**Flow:**
1. **Address entry** — user lands on the tool and types in a property address.
2. **Questionnaire** — a 3-step accordion flow:
   - Step 1: Renovation type (Internal or External)
   - Step 2: What to renovate
   - Step 3: More questions
3. **Estimate / report display** — a cost estimate is shown (possible third screen still to be confirmed via Figma reference).

This is a modernization/rebuild effort: the existing legacy version already works (reference design captured from Figma "Spike Reno Calculator" file), and this project re-platforms the front-end onto React. **Scope is front-end only** — using static/mock values for now, with no backend or live data integration in this phase.

---

## Challenge / Opportunity

The existing Renovation Calculator Report runs on legacy technology. The business wants to rebuild it using a modern tech stack (ReactJS) to keep the tool maintainable and extensible going forward.

The tool serves two audiences with related but distinct motivations:
- **Homeowners** — want to estimate renovation costs before a buy/sell decision.
- **Real estate agents** — want a report they can use to support a property listing.

## Design Goals

- Faithfully reproduce the existing UX/visual design captured in Figma (address entry → 3-step questionnaire → estimate display), matching measurements, typography, spacing, and color tokens already extracted from the design file.
- Success for v1 = clearly displaying the cost estimate to the user. No further action (lead capture, contact request, quote follow-up) is required at this stage.
- Keep the experience simple and self-contained for a standalone, direct-URL access pattern.

## Constraints

- **Scope:** Front-end only — no backend/API work in this phase.
- **Data:** Static/mock values used in place of live renovation cost calculations.
- **Tech stack:** ReactJS.
- **Access:** Standalone tool, accessed via direct URL; no authentication or discovery/embedding layer yet.
