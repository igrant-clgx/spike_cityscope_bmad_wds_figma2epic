## Overview

**Page Purpose:** Let Hannah enter the property address so the tool can begin the renovation cost estimation flow.

**Entry Context:** Hannah opens the direct URL for the Renovation Calculator on her phone while thinking about a property she's interested in. There's no prior page — this is the tool's entry point.

**User Situation:** Mid-30s to 50s homeowner, browsing in spare moments, either considering renovating her current home or eyeing a new property before purchase.

**Mental State:**
- **Hope:** Get a fast, clear cost estimate she can trust without chasing contractors.
- **Worry:** Discovering the property is a "money pit" with hidden renovation costs after she's already committed.

**Discovery Method:** Direct URL — standalone tool accessed via shared link or bookmark, no search/discovery layer.

**Exit Action:** Enters/selects the property address, proceeds to the questionnaire (1.2).

**On-Page Interactions:**
- Address input field with autocomplete/search icon (per Figma reference)
- "Address not showing?" link → "Use advanced search" option for edge cases where address isn't found

## Design Intent (Phase 4)

**Business Goal:** Capture a valid address to kick off the flow, keeping friction minimal.

**Main User Goal:** Quickly find and confirm her property so she can move to the questionnaire.
