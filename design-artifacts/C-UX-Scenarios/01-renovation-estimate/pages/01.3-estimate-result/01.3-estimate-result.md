## Overview

**Page Purpose:** Communicate the indicative renovation-cost range, explain available context, and provide clear edit, restart, address-change, and contact actions.

**User Situation:** The user completed the renovation questionnaire and the estimate service returned a valid result.

**Success Criteria:** The user understands that the range is indicative, can inspect how it was calculated, and can confidently choose a next action.

**Entry Points:**

- Successful estimate calculation from Renovation Details.

**Exit Points:**

- Edit Estimate -> restore prior answers.
- New Estimate -> reset answers for the selected address.
- Enter new address -> restart property selection.
- Phone links -> device phone handler.

**SEO:** `noindex, nofollow`; the result may contain user-specific context.

## Error Handling

| Code | Condition | English | Recovery |
|------|-----------|---------|----------|
| `ERR_RESULT_MISSING` | Result route lacks a valid payload | Your estimate is no longer available. Return to your renovation details to calculate it again. | Details |
| `ERR_ESTIMATE_UNAVAILABLE` | Estimate service failed | We couldn't calculate the estimate. Try again or edit your answers. | Retry or edit |
| `ERR_EXPLANATION_UNAVAILABLE` | Explanation payload failed | Calculation details are temporarily unavailable. | Retry disclosure content without hiding the estimate |

## Responsive and Accessibility Requirements

- Cost range remains readable without horizontal overflow at 320 CSS px.
- Dynamic result is announced through a polite live region after the result heading.
- The disclosure uses a native button within an `h2`, with `aria-expanded` and `aria-controls`.
- Action order remains Edit Estimate then New Estimate in reading order; visual emphasis does not change semantics.
- Phone numbers are links with human-readable labels and normalized `tel:` values.
- Icons are decorative because adjacent text supplies meaning.
- Focus returns to the relevant heading after navigation and to the error summary after failed calculation.
- Respect reduced-motion preferences; no animation is required.

---

## Technical Notes

- Route guard requires a result tied to the current property and answer-set version.
- Format monetary values with `Intl.NumberFormat` or equivalent and API-provided currency/locale.
- Never derive or recalculate the range in the browser unless the approved architecture explicitly requires it.
- Reset actions clear only the state described in their interaction contracts.
