## Overview

**Page Purpose:** Collect the renovation choices required to calculate an indicative cost range.

**User Situation:** The user has selected a valid property and needs to describe the renovation.

**Success Criteria:** Required answers are complete, an estimate request succeeds, and the result page receives the property and answer context.

**Entry Points:**

- Valid address selection from Address Search.
- Edit Estimate or New Estimate from Estimate Result.

**Exit Points:**

- Successful calculation -> Estimate Result.
- Enter new address -> Address Search.

**SEO:** `noindex, nofollow`; this is a transactional form route.

#### Accordion Semantics

- Each heading contains a native button with `aria-expanded` and `aria-controls`.
- Locked steps are disabled and expose the unmet prerequisite in accessible helper text.
- Only the current step is expanded by default; completed steps can be reopened without losing answers.
- Selecting a different Step 1 value clears only downstream answers that are no longer valid.
- Auto-opening the next step moves focus to its heading, not directly into the first control.

#### Button States

Default, hover, pressed, focus-visible, selected, and disabled use semantic state tokens. Selected state must include more than color alone.

## Page States

| State | When | Appearance | Actions |
|-------|------|------------|---------|
| Default | Property and questionnaire ready | Step 1 expanded; Steps 2-3 locked | Choose type or change address |
| Empty | Property context missing | Missing-session notice replaces form | Return to Address Search |
| Loading | Restoring answers/configuration | Questionnaire skeleton; address retained | Wait or change address |
| Error | Form config or estimate request fails | Error alert; completed answers retained | Retry or edit |
| Success | Estimate request succeeds | Completion/progress announcement | Automatic result navigation |

**Component states:**

- Step 1: expanded current; collapsed completed; hover; focus-visible.
- Step 2: locked; enabled collapsed; expanded current; completed; error.
- Step 3: locked; enabled collapsed; expanded current; submitting; completed; error.

## Validation and Errors

| Field / Group | Rule | Timing | Code | English |
|---------------|------|--------|------|---------|
| Renovation type | Exactly one type selected | Attempt to open Step 2 | `ERR_RENOVATION_TYPE_REQUIRED` | Choose Internal or External renovation to continue. |
| Renovation items | At least one available item selected | Attempt to open Step 3 | `ERR_RENOVATION_ITEM_REQUIRED` | Choose at least one area to renovate to continue. |
| Follow-up questions | Every displayed required question answered; hidden conditional questions excluded | On change and before submit | `ERR_RENOVATION_DETAILS_REQUIRED` | Answer all required questions to calculate your estimate. |
| Estimate request | Service succeeds for current property/answers | After submit failure | `ERR_ESTIMATE_UNAVAILABLE` | We couldn't calculate the estimate. Try again or edit your answers. |

Errors appear adjacent to the relevant step and are summarized in a focusable alert when submission fails.

---

## Responsive and Accessibility Requirements

- Use a single column on mobile; retain a readable maximum content width on larger screens.
- Buttons have at least 44x44 touch targets and wrap without truncating labels.
- Accordion focus, expanded, completed, selected, locked, loading, and error states do not rely on color alone.
- Preserve answers when navigating backward or reopening a completed step.
- Announce step changes and calculation progress politely; errors use assertive announcement only when submission fails.
- Focus the first invalid step heading on failed submission.

---

## Technical Notes

- Route guard requires a valid selected-property identifier; missing state returns to Address Search without rendering stale data.
- Questionnaire content should be configuration-driven so conditional questions and validation share one schema.
- Estimate submissions must be idempotent or protected from duplicate activation.
- No expanded Step 2 or Step 3 content appears in the supplied Figma frame.
