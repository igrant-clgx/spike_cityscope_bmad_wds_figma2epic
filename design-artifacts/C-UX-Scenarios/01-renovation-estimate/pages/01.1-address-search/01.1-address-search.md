## Overview

**Page Purpose:** Find and select the property for which the user wants a renovation estimate.

**User Situation:** The user is starting the calculator from a public entry point or returning to replace a previously selected address.

**Success Criteria:** A valid address suggestion is selected, its property identifier is retained, and the user reaches Renovation Details.

**Entry Points:**

- Direct public route.
- Marketing or product link to the calculator.
- "Enter new address" from Renovation Details or Estimate Result.

**Exit Points:**

- Valid address selection -> Renovation Details.
- Advanced Search -> alternate address-entry flow.

#### Property Address Input

| Property | Value |
|----------|-------|
| Accessible label | Property address |
| Type / role | `search`; ARIA combobox with listbox suggestions |
| Required | Yes |
| Maximum length | 200 characters |
| Browser autocomplete | `street-address` |
| Autofocus | Desktop only; avoid forced mobile keyboard |
| Query behavior | Debounced lookup; keyboard arrows navigate; Enter selects |
| Submission | Only a selected lookup result is valid |

**Input states:** default, focus-visible, typing, loading suggestions, suggestions available, filled, no results, lookup error, disabled.

**Error messages:**

| Code | Condition | English |
|------|-----------|---------|
| `ERR_ADDRESS_REQUIRED` | Empty after interaction | Enter a property address. |
| `ERR_ADDRESS_TOO_LONG` | More than 200 characters | Use 200 characters or fewer. |
| `ERR_ADDRESS_NOT_SELECTED` | Free text without selected result | Select an address from the suggestions. |
| `ERR_ADDRESS_NOT_FOUND` | No usable match | We couldn't find that address. Try another address or use advanced search. |
| `ERR_ADDRESS_LOOKUP_UNAVAILABLE` | Lookup service failure | Address search is temporarily unavailable. Try again. |

## Responsive and Accessibility Requirements

- Maintain WCAG AA contrast for all text and controls over every hero crop; add a semantic overlay token when required.
- Keep a minimum 44x44 touch target for interactive controls.
- Suggestions use combobox/listbox semantics, `aria-activedescendant`, Escape to close, and a polite live region.
- Focus order follows visual order; focus indicators must not rely on color alone.
- At narrow widths, stack or hide the partner logo only if brand requirements allow; never distort either logo.
- Respect reduced-motion preferences; this page requires no decorative animation.

---

## Technical Notes

- The selected suggestion must provide a stable property identifier, not only display text.
- Cancel or ignore stale lookup responses when a newer query exists.
- Preserve the query after recoverable errors.
- The hero is expected to be the LCP asset; provide responsive image sources and explicit dimensions.
